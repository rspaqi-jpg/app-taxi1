# Go Taxi Gjakova

Ky repository është caktuar për projektin **Go Taxi Gjakova** dhe do të mbahet i ndarë nga Albabook.

## Projekti
- Rezervime taksie në Gjakovë
- Hartë OpenStreetMap dhe GPS për shoferin
- Kërkim adresash dhe rrugë me OpenStreetMap/Nominatim dhe OSRM
- Panel shoferi dhe histori udhëtimesh
- Rrotë shpërblimi pas 20 udhëtimeve të përfunduara

> Shënim: Ky është skedari fillestar i projektit; skedarët e aplikacionit ende nuk janë ngarkuar.
